④ صاحبك يدخل إزاي؟

  1. ابعتله ملفات اللعبة (الـ ZIP) + ملف البيانات (نفس نسختك).
  2. لو هو في بيت تاني: الاتنين تدخلوا نفس شبكة VPN (Radmin أو Hamachi).
  3. أنت تشغّل python lan_host.py وتسيب الصفحة دي مفتوحة للمراقبة.
  4. تفتح اللعبة (index.html) → أونلاين → إنشاء لوبي → تكتب الرمز + IP الظاهر فوق.
  5. صاحبك يفتح اللعبة → أونلاين → انضمام → نفس الرمز + نفس الـ IP ويرفع نفس ملف البيانات.
