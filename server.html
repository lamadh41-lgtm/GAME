السيرفر متوقف

1) شغّل على جهازك: python lan_host.py
2) للأونلاين العام (من غير VPN) في تيرمينال تاني:
cloudflared tunnel --url http://localhost:27100
3) الصق رابط https://xxxx.trycloudflare.com في خانة العنوان فوق، أو استخدمه في اللعبة.

④ صاحبك يدخل إزاي؟ (من أي مكان — من غير VPN)

  1. أنت تشغّل python lan_host.py وتسيب النافذة مفتوحة.
  2. تشغّل نفق عام: cloudflared tunnel --url http://localhost:27100
  3. تنسخ الرابط https://....trycloudflare.com وتبعته لصحابك.
  4. تفتح اللعبة → أونلاين → إنشاء لوبي → الرمز + نفس الرابط.
  5. صاحبك: أونلاين → انضمام → نفس الرمز + نفس الرابط + يرفع نفس ملف البيانات.

لو الاتنين على نفس الشبكة (أو Radmin): ممكن تستخدم IP المحلي بدل الرابط العام.
